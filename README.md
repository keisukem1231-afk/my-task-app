追加: setTasks([...tasks, newTask])

削除: setTasks(tasks.filter(...)) で対象を除外

DOM直接操作を使わない理由

setを呼べばReactが差分を見つけて自動で描き直してくれるため、「どのDOMをどう書き換えるか」を自分で管理する必要がなく、stateと画面のずれが起きない。
